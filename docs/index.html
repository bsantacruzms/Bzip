BoltZip

A modern, open-source archiver that tunes itself to your hardware — and ships a fast, authenticated-encryption format.

Download View on GitHub

Free & open source · Windows today · macOS & Linux in progress

Why BoltZip is different

🧠

Automatic hardware optimization

Profiles your CPU cores, RAM and storage (NVMe/SSD/HDD/network) and auto-tunes threads, window size, buffers and codec — per job. And it tells you why.

🔒

Modern authenticated encryption

The native .bz format uses XChaCha20-Poly1305 with Argon2id key derivation. Tampering and wrong passwords fail loudly, not silently.

⚡

Fast modern codec

Built on Zstandard, which beats classic Deflate/LZMA on the speed-vs-ratio curve and scales across every core.

🆓

Free, open, no nag screens

No ads, no upsells, no trials. MIT-spirited and fully open source.

📦

Portable & scriptable

Single-file executables, a friendly bz CLI, and a Windows right-click menu when you install it.

🌍

Cross-platform core

One Fluent desktop app for Windows, macOS and Linux — powered by the same .NET engine.

Get BoltZip

Windows

Installer (.msi) adds the app, the bz CLI, the right-click menu, and optional file associations so archives open in BoltZip. Or grab the portable .exe.

Download for Windows

macOS

A .dmg drag-to-Applications build (Apple Silicon & Intel). Archives open with BoltZip from Finder’s “Open With”.

Releases

Linux

.deb, .rpm and a portable tarball with the bz CLI. Registers the .bz type and file-manager associations.
